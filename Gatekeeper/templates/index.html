Cloudflare Tunnel Setup

Quick Setup Guide:

  1. Install cloudflared on this gateway machine
  2. Run cloudflared tunnel login
  3. Create tunnel: cloudflared tunnel create --name gatekeeper
  4. Enter Tunnel ID above and click "Generate Config"
  5. Run tunnel: cloudflared tunnel run --config cloudflared_configs/config.yml
